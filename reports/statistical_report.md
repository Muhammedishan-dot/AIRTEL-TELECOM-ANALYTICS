
QUESTION 1

# Claim: The two groups used the same amount of data before the offer.

# H₀: Both groups have the same true average daily data usage before May.

# H₁: The two averages differ.

F-test:
F = 0.9003
P-value = 3.673 × 10⁻⁸

Decision: Variances differ.

Z-test:
Z = -0.5191
P-value = 0.6037

Decision: Fail to reject H₀.

Conclusion:
There is insufficient evidence that the groups differed in their average daily data usage before the offer. The groups are considered balanced on this important pre-offer measure.
